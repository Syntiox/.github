## 1. Atom-MD (AI-Powered WhatsApp Engine)
**The smartest, 100% Free, No-Coding WhatsApp Bot.**

* **Official Website:** [http://atom.syntiox.top/](http://atom.syntiox.top/)
* **Get Started / Connect:** [http://atom.syntiox.top/connect.html](http://atom.syntiox.top/connect.html)
* **Dashboard:** [http://atom.syntiox.top/dash.html](http://atom.syntiox.top/dash.html)

### 🔥 Key Features:
* 🤖 **AI Chat Assistant:** Ask anything, generate futuristic images (using `.img`), and summarize texts directly in WhatsApp. Powered by Gemini Omni.
* 📥 **Media Downloader:** Paste a YouTube, TikTok, Facebook, or Instagram link and get the video/audio instantly with NO watermarks.
* 🛡️ **Privacy Guard:** See deleted messages, save view-once photos forever, and auto-block annoying calls.
* ⚙️ **Auto Replies:** Set keywords (like "price" or "hello") to trigger automatic replies when busy (up to 6 rules).
* ☁️ **Runs 24/7:** Runs completely on the cloud. Uses almost no resources and never crashes.

### 🚀 How to Setup (4 Simple Steps):
1. **Login with Google:** First, go to the Connect page and Sign in using your Google Account.
2. **Scan a QR Code:** After logging in, go to WhatsApp -> Linked Devices, and scan the QR code shown on the screen.
3. **Get Your Password:** A dashboard password is automatically sent to your WhatsApp inbox in seconds (Forgot it? Use `.resetpassword`).
4. **Turn On What You Want:** Log into the Dashboard using that password and toggle features on/off. Zero coding required!

### ❓ FAQs:
* **Is it really free?** Yes, 100% free with no hidden fees. (Advanced AI features just need a free Google API key).
* **Will I get banned?** No. Atom-MD uses the official WhatsApp Multi-Device protocol with advanced anti-ban protection.
